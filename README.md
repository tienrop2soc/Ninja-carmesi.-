# Sombra Carmesí

Juego de plataformas ninja en HTML5 Canvas (20 niveles, jefes, armas en cajas). Funciona como web app instalable (PWA), pensado para móvil en horizontal.

## Controles
- Teclado: ← → / A D mover · ↑ / W / Espacio saltar · X / J atacar · ↓ / S bajar de plataforma · Esc / P pausa
- Móvil: botones táctiles en pantalla

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube **el contenido** de esta carpeta (no la carpeta en sí) a la rama `main`.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)` → Save.
4. En 1–2 minutos estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Instalar en el móvil
Abre la URL en Chrome (Android) → menú ⋮ → *Instalar app* / *Añadir a pantalla de inicio*. En iPhone: Safari → Compartir → *Añadir a pantalla de inicio*.

## Actualizar
Tras cambiar archivos, sube el número de versión de `CACHE` en `sw.js` (por ejemplo `sombra-carmesi-v2`) para que los jugadores reciban la actualización.
